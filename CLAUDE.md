# Repository instructions

## Commit authorship

This is a solo-maintainer repository. The GitHub repo sidebar's "Contributors" widget
lists anyone credited via a `Co-authored-by:` trailer in a commit message as a
separate contributor, regardless of the actual git author. Do **not** add a
`Co-Authored-By: Claude ...` (or any AI-assistant) trailer to any commit in this
repository, even if that is your default commit-message behavior elsewhere. Commit
messages in this repo should credit only the repository owner.

This applies to every commit, in every session, including merge commits.
